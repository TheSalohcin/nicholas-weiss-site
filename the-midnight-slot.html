The Midnight Slot

One tape. Four broadcasts recorded over each other. You're the overnight editor and the station signs off at dawn.

HOW TO RESTORE A FRAME
1. Every frame edge carries a coloured signal.
2. Touching edges must carry the same signal, or the picture tears.
3. The outside of the frame must be dead static — signal can't run off the tape.
4. Frames burned into the tape can't be moved. Start there.
Later slots let you rotate frames, and some rows are missing their atomic totals. Those add up.
